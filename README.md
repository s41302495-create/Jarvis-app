# JARVIS Flutter starter

This is a real Flutter source project with:
- Dark JARVIS-style chat UI
- Configurable OpenAI-compatible OmniRoute endpoint
- Model/combo selector field (enter your OmniRoute combo name, such as `Ai`)
- API key stored with `flutter_secure_storage`
- HTTP error and timeout handling

## Important
This ZIP contains Flutter source code, not a prebuilt APK. The Android platform folder is generated by Flutter.

## Build on a computer with Flutter + Android SDK
1. Extract this ZIP.
2. In the project folder run:
   ```bash
   flutter create . --platforms=android
   flutter pub get
   flutter run
   flutter build apk --release
   ```
3. APK output:
   `build/app/outputs/flutter-apk/app-release.apk`

## Android / Termux note
Termux is useful for extracting/editing files and using Git, but a complete Android APK build from Termux is not a reliable officially supported Flutter workflow. The easiest build route is a computer with Flutter + Android SDK, or a cloud CI build such as GitHub Actions.

## OmniRoute connection
Open JARVIS > Settings and enter:
- API base URL: your reachable OmniRoute URL ending in `/v1`
- API key: the key accepted by your OmniRoute server (if required)
- Model / combo name: your actual OmniRoute combo/model identifier

The starter uses `POST {baseUrl}/chat/completions` with an OpenAI-compatible request. Confirm the endpoint and model identifier in your OmniRoute configuration. If OmniRoute runs in Termux on the same phone, `127.0.0.1` may work only if the server is listening on the phone's loopback interface and the app can reach it. Use the actual port shown by your OmniRoute setup; do not assume the example port.

## Current scope
This is the first functional chat milestone. It does not yet include voice, long-term memory, game/app generation, streaming UI, or quota-aware provider selection. Those should be added and tested in later milestones.
